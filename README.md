# WGU Lab

My personal learning lab documenting my progress through the **Western Governors University B.S. Cybersecurity and Information Assurance program**.

This repository is designed to grow alongside my degree. It serves as a place to document what I am learning, build hands-on technical skills, experiment with new technologies, develop study workflows, prepare for certifications, and preserve projects and labs as my knowledge develops.

Rather than only documenting the finished product, I want this repository to show the learning process itself.

## Repository Goals

- Build practical cybersecurity skills
- Develop strong Linux administration skills
- Learn and apply PowerShell
- Learn Python and scripting
- Build networking knowledge
- Practice Active Directory administration and security
- Work with virtualization and containers
- Build cybersecurity labs and projects
- Prepare for industry certifications
- Develop effective technical learning workflows
- Improve my Git and GitHub skills through regular use
- Build a professional technical portfolio throughout my degree

## Repository Structure

The repository is organized by technology, skill area, and type of learning artifact.

### `active-directory/`

Active Directory labs, administration practice, configuration, and security exercises.

### `certifications/`

Certification preparation, notes, practice resources, and related projects.

### `cybersecurity/`

General cybersecurity concepts, exercises, labs, and security projects.

### `docker/`

Containerization practice and Docker-related labs.

### `linux/`

Linux administration, command-line practice, configuration, troubleshooting, and labs.

### `networking/`

Networking concepts, configuration exercises, troubleshooting, and labs.

### `notes/`

Technical notes and reusable learning references that do not belong to a more specific area.

### `powershell/`

PowerShell commands, scripts, automation practice, and Windows administration exercises.

### `prompts/`

Reusable AI-assisted learning workflows and prompts developed during my studies.

One example is the **WGU Study Hall Prompt**, which defines how I use AI as a tutor to prepare for upcoming courses while maintaining academic-integrity boundaries.

### `python/`

Python learning exercises, scripts, automation, and future security-related projects.

### `scripts/`

Reusable scripts and automation that span multiple technical areas.

### `virtualization/`

Virtual machines, lab environments, hypervisors, and virtualization experiments.

### `web/`

Web technologies, web-security learning, and related experiments.

## WGU Study Hall

One of the first reusable learning tools developed in this repository is my **WGU Study Hall Prompt**.

Study Hall is an AI tutoring workflow designed to help prepare for upcoming WGU courses before beginning them.

The prompt includes:

- Configurable mastery targets
- Objective Assessment (OA) preparation
- Performance Assessment (PA) preparation
- Rapid-fire quizzes
- Hint-based multiple-choice learning
- Adaptive teaching methods
- Subject rotation
- Mobile and voice-dictation study
- Session continuity
- Academic-integrity safeguards

The prompt is available here:

[`prompts/study-hall.md`](prompts/study-hall.md)

It is designed to be reusable and customizable by other students.

## Learning Philosophy

This repository is intentionally a work in progress.

Not every directory represents a completed skill or finished project. Some directories exist because they represent technologies and subjects I expect to encounter as my degree progresses.

The goal is to document progression rather than create the appearance that I already know everything contained here.

Mistakes, revisions, improved scripts, better documentation, and increasingly complex projects are part of that progression.

Git history is part of the learning record.

## Academic Integrity

This repository contains my own learning artifacts, technical practice, projects, notes, and study tools.

It is not intended to distribute proprietary WGU course materials, assessment questions, rubrics, or other protected instructional content.

Any AI-assisted learning resources in this repository are intended for tutoring, practice, and skill development—not for completing graded assessments on behalf of a student.

Students using anything from this repository are responsible for following current WGU academic-integrity requirements, AI-use policies, assessment rules, and course-specific instructions.
